# Ambiance for Qt Widgets

Based on KvAmbiance from Kvantum 1.1.8 by Pedram Pourang (Tsu Jan).
Upstream: https://github.com/tsujan/Kvantum/tree/V1.1.8/Kvantum/themes/kvthemes/KvAmbiance
License: GPL-3.0-or-later; see COPYING.

Local changes: compact desktop control and tab metrics; disable transient
scrollbars and size-grip injection. Tab artwork uses the same warm grey / ivory
contrast as the GTK theme. All SVG source remains editable.

Requires the Kvantum style plugin for the application's Qt major version.
Select this directory in Kvantum Manager (Install/Update Theme), then select
Ambiance. Choose the kvantum widget style in qt5ct/qt6ct on Xfce.
Qt Quick/QML uses a separate styling system.
